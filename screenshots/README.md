# Screenshot capture guide

These screenshots must be captured from the live application—not from static mockups—so the README accurately represents the current interface and indexed Base data.

| File | Route | Viewport |
| --- | --- | --- |
| `discover-desktop.png` | `/` | 1440 × 1000 |
| `discover-mobile.png` | `/` | 390 × 844 |
| `token-desktop.png` | `/token/0xB200000000000000000000Fa2F036b02356E2b07` | 1440 × 1000 |
| `token-mobile.png` | Same official token route | 390 × 844 |
| `launch-desktop.png` | `/launch` | 1440 × 1000 |
| `launch-mobile.png` | `/launch` | 390 × 844 |
| `transparency-desktop.png` | `/transparency` | 1440 × 1000 |

Before capturing, configure the production Factory, Supabase, and server RPC environment variables, run `pnpm dev`, wait for loading skeletons to resolve, and ensure no wallet modal or private account information is visible. Optimize PNG files before committing them.
